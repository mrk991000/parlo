# Parlo

A desktop chat app for talking to different AI models: compare two models side by side, watch the cost live
Built with React + Vite + Electron.

## Features
- First-run guide connects a free model in about two minutes
- Works with Claude, GPT, Gemini, Groq, OpenRouter, Mistral and Ollama (free options included)
- Streaming replies, markdown + code blocks
- Compare mode: two models answer side by side, pick the winner
- Live token and cost meter
- Global hotkey Ctrl+Shift+Space (Cmd on Mac) opens the app with your clipboard attached


## How to use

On first launch connect at least one provider (Providers and keys screen). Free options: Gemini, Groq,
OpenRouter, Mistral, or Ollama running on your own PC.
